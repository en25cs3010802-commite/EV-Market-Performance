# EV Market Performance Dashboard

## Project Overview
An interactive Tableau dashboard for analyzing electric vehicle market trends, sales, and manufacturer performance.

## Tools Used
- Tableau
- Data Visualization
- CSV Dataset

## Project Files
- Tableau dashboard workbook
- Dataset
- Dashboard screenshots

## Objective
To explore EV market growth and identify key insights through interactive visualizations.

## How to View
Download the `.twbx` file and open it using Tableau Desktop or compatible Tableau software.
